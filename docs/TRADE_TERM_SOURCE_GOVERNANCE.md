# INCO Trade-Term Source Governance

**Version:** 0.1  
**Date:** 2026-08-05  
**Status:** Governing source note

## 1. Source ID

`INTERNAL-TRADE-001`

## 2. Description

Approved complete trade-term rules reference retained outside this public repository under controlled access.

## 3. Usage

Permitted repository use:

- Original structured rule logic.
- concise operational summaries.
- responsibility mappings.
- risk and clarification triggers.
- test scenarios.
- source ID traceability.

Not permitted:

- Uploading or copying the protected source file.
- reproducing protected tables or extended passages.
- publishing organization-owned wording as INCO content.
- implying endorsement, affiliation, certification, or official status.

## 4. Verification Workflow

1. Draft the INCO rule in original language.
2. Check delivery, risk, cost, insurance, and clearance concepts separately.
3. Link the rule to `INTERNAL-TRADE-001`.
4. Review the structured record against the controlled source.
5. Record rule version and verification date.
6. Test representative transaction scenarios.
7. Publish only the original INCO explanation and decision logic.

## 5. Public Product Rule

INCO presents professional decision support using its own wording and workflow. It must not expose the protected reference, its internal evidence files, or restricted source text.

## 6. Review Status

The machine-readable records created from `docs/TRADE_TERM_RULE_MATRIX.md` remain `draft` until the full eleven-term dataset is checked record by record against the controlled reference and the acceptance fixtures pass.
